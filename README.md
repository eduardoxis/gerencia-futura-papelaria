# Gerência Futura Papelaria

Painel administrativo separado da Papelaria Futura.

Este projeto usa o mesmo Firebase do site e do sistema da Futura (`papelaria-futura`), portanto produtos, estoque, caixa, clientes, cotações, promissórias e usuários continuam compartilhados entre os dois ambientes.

## Acesso

- `/` ou `/login`: tela de login
- `/dashboard`: painel administrativo

O projeto mantém as regras de acesso e os cargos já existentes no Firebase da Futura.
